# Code of conduct

## The short version

Be direct about the work and decent to the person. Critique the code, not the
author. Assume the other person is competent and has a reason for what they
did, then ask what it was.

## Expected

- Technical claims carry evidence: a test, a measurement, a citation.
- Disagreement is stated plainly and early, with the reason.
- A mistake is corrected in public if it was made in public.
- Reviews say what is wrong and what would make it right.

## Not acceptable

- Personal attacks, harassment, or demeaning comments.
- Dismissing a report of a defect because the reporter is new.
- Publishing private information without consent.
- Sustained disruption of a technical discussion.

## Scope

Issues, pull requests, commit messages, and any space where this project is
discussed.

## Enforcement

The repository owner decides. A first response is a private request to stop. A
repeated or serious case ends participation. Reports are handled privately.

## Attribution

This is a short, project specific policy, not the Contributor Covenant. It
covers the behaviour that matters here without borrowing language that nobody
reads.
